Musik — Violin_Ear_Trainer v2.2.9
========================================
本版本基于此前提供的 v18.8 / v2.2.8 REBUILT 审阅源码重建，
不是线上部署文件的逐字节备份。请保留部署前备份。

新增：
1) AP learning 先在标注音名的记忆卡上反复听，随后不限时回答。
   每题正确音单次反馈，可手动重听；错题与到期音在下一组加权出现。
   复习间隔为设计启发式：1、3、12、60 分钟和 1、3、7 天，
   并非对艾宾浩斯遗忘曲线的精确拟合。
2) 新增 Relative pitch course (RP)，L0-L12 可自由选级。
   项目包含带标签聆听示范、引导练习、弱音程加权复习、
   无逐题反馈独立测评、虚拟乐器定位和三音短旋律最后一步辨认。
   首版以内置音程半音距离计分，不以未提供的乐谱拼写判分。
3) 相对音程课程有独立的、按音程类别抽样的出题器。
   标准测评使用共同参考音域、等概率独立抽类别和方向，
   不禁止连续同类或重复音对，以免产生靠顺序猜题的漏洞。
4) 小提琴完整四弦纵向指板、0–12 半音全部触点同步显示。
   Two notes 参考音持续可见；隐藏翻页按钮。
5) 继承原有 AP 正式测评、冷测、Two notes、Demo、六语言、
   云端训练时间同步及既有本地历史。

使用：解压 site.zip 中全部根目录文件，覆盖原项目中对应静态资源。
Cloudflare 训练时间同步 Worker 和 Chrome 监督插件无须改动。
由于 PWA 使用 service-worker 缓存，部署后请刷新页面，必要时
关闭并重新打开已安装 PWA，确认已载入最新缓存版本。

数据与适用范围：
- AP 记忆计划和 RP 训练记录分别保存在该站点本地 localStorage，
  不通过已有训练时间 Worker 跨站同步。RP 可导出 CSV。
- 记忆卡按已学音名显示；已学集合及现有 AP 历史保留。
- 课程晋级仅作建议，所有关卡都可以手选。
- RP L11/L12 复音程在小提琴音域内选择单向练习；不能在
  双向同时使用时偷换参考音区。默认切换到上行。
- 相对音程按钮测到的是类别辨认，不保证自动转移到真实
  小提琴音准控制；真实演奏与音色迁移仍需另行评估。

测试记录：
- 浏览器无网络权限下，使用模拟播放器完成钢琴和小提琴主要
  答题流程（AP学习、RP练习/短测/乐器定位、Two notes 参考音）。
- 两站 JavaScript 语法检查通过；RP 13级×两站边界抽样验证通过；
  AP v3 原有随机性测试通过。
- Demo score 与前一份 REBUILT 源码逐字节一致；training-tracker.js
  逐字节一致，未修改 Cloudflare 同步协议。
- 真实手机音频和 PWA 更新安装体验尚未实机验证。
